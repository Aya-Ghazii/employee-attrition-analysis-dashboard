
# دليل نشر نظام تحليل الموارد البشرية | HR Analytics System Deployment Guide

## التثبيت | Installation

### 1. تثبيت Python والمكتبات | Install Python and Libraries
```bash
pip install -r requirements.txt
```

### 2. تشغيل النظام | Run the System
```bash
streamlit run hr_complete_deployment.py
```

### 3. رفع الملفات | Upload Files
- ارفع ملفات Excel العربية من خلال الواجهة | Upload Arabic Excel files through the interface
- تأكد من تنسيق البيانات الصحيح | Ensure correct data format

## الاستخدام | Usage

### تحليل البيانات | Data Analysis
1. ارفع ملفات البيانات | Upload data files
2. راجع الإحصائيات الرئيسية | Review main statistics
3. اطلع على الرسوم البيانية | View charts and graphs

### النمذجة التنبئية | Predictive Modeling
1. اضغط "تدريب النموذج" | Click "Train Model"
2. راجع دقة النموذج | Review model accuracy
3. استخدم التنبؤات في التخطيط | Use predictions for planning

### التوصيات | Recommendations
- راجع التوصيات الاستراتيجية | Review strategic recommendations
- طبق خطة العمل المقترحة | Implement suggested action plan
- راقب التحسن في معدلات الاستقالة | Monitor improvement in attrition rates
